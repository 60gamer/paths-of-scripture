# Paths of Scripture

A cinematic, interactive story game inspired by biblical lessons on faith, wisdom, humility, and repentance.

## Features
- Branching story choices inspired by biblical figures
- Combat encounters using prayer, scripture, faith, and healing actions
- Auto-save and continue support with localStorage
- Responsive and animated interface for desktop and mobile
- Keyboard-friendly interactions and reduced-motion support
- Background music toggle with lightweight synthesized tones

## Run locally
Open `index.html` directly in a browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files
- `index.html` — structure and UI layout
- `styles.css` — visual design, transitions, responsive layout, and effects
- `script.js` — story logic, combat system, save system, and audio controls

## Notes
This project is intentionally dependency-free so it can run in any browser without a build step.
